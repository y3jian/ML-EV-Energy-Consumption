# ML-EV-Energy-Consumption

## Large processed files (dataset 3)

GitHub rejects files **> 100 MB**. The EV population **processed** CSVs (`data/processed/3-EV_population_data_*.csv`) are gitignored. After cloning, run **`3-EV_population_data_prep.ipynb`** through the **Export** cells to regenerate them locally (raw data stays in `data/raw/`).
