# ML-EV-Energy-Consumption

## Large files (dataset 3)

GitHub blocks files **> 100 MB**. The dataset 3 cleaned table and train/validation/test splits live in `data/processed/` for modeling. If you regenerate dataset 3 and a CSV grows beyond GitHub's limit, rerun `3-EV_population_data_prep.ipynb` with compact export settings before committing.
